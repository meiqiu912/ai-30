
**去掉AI味**
```

1. 删掉"总而言之""综上所述"等AI常用词
2. 增加口语化表达和具体细节
3. 句子长短结合
4. 允许有个人观点和情绪
原文：[粘贴你的文字]
```

**小红书爆款笔记**
```

请按以下结构帮我写一篇关于[主题]的小红书笔记：
1. 标题：带数字或悬念，20字以内
2. 开头：第一句抓住人（痛点/反常识/结果前置）
3. 正文：3-5个要点，每点配emoji
4. 结尾：引导收藏+关注
5. 配3个话题标签
```

```
2. 中间：3个干货点，结论先行再用例子
```
