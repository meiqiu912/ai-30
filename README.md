## 免费试吃：3 条最常用的提示词

**① 万能写作公式**
```
你是一位资深[领域]写作专家，拥有10年[领域]内容创作经验。
请帮我写一篇关于[主题]的文章。
要求：
1. 目标读者是[目标人群]
2. 核心目的是[涨粉/带货/科普/说服]
3. 语气[轻松/专业/热情/严肃]
4. 结构包含：抓眼球的开头、3个有干货的中段、有行动号召的结尾
5. 字数[500-800字]
6. 写完后给出3个备选标题
```

**② 10 个爆款标题**
```
你是一个爆款标题专家。我写了一篇关于[主题]的文章，核心内容：[一句话概括]。
请给我10个爆款标题，要求：包含数字、悬念、对比、痛点、利益点中至少2种元素；
字数15-30字；不夸大不标题党，但足够吸引人。
```

**③ 小红书种草文案**
```
你是一位小红书爆款笔记写手。请为[产品/服务]写一篇小红书笔记，目标人群[人群]。
要求：开头3秒抓眼球；正文口语化有画面感，多用emoji和换行；
结尾引导互动；标题15-20字含关键词；附8-10个话题标签。
```
